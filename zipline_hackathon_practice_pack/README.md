# Practice pack — read this before starting

The U.S. commercial datasets are **already generated** in `data_us_commercial/`. You do **not** need to run `generate_us_commercial_pack.py` to start the practice hackathon. That file only exists so the synthetic pack can be reproduced or changed later.

For the simulation, open [CHALLENGE_BRIEF.md](CHALLENGE_BRIEF.md), set a 3.5-hour timer, and work only from the brief and the contents of `data_us_commercial/`. There is deliberately no answer key or build tutorial in this candidate-facing packet.

The old `data/` folder is a retired medical-delivery pack. Do not use it for this exercise. The setting is fictional and designed to practice a U.S. consumer/retail Operations Copilot; it is not real Zipline data, policy, or operational guidance.
